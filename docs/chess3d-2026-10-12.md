# Chess(3d) implementation and verification

## Scope

Chess(3d) is a separate entry next to Chess in plugin and web/mobile game lists.
The original 2D game remains unchanged. Both clients lazy-load the shared
Three.js renderer in `packages/core/components/Chess3DBoard.tsx`.

The supplied reference informed the walnut/maple board, natural light pieces,
polished dark pieces, Staunton silhouettes, straight elevated perspective,
yellow-green square highlights. Board textures are seeded local bitmaps.
The room, shallow wide walnut desk and opposite upholstered walnut chair now
share one photographic asset, `packages/core/assets/chess-table-room.webp`.
The interactive board sits within its tabletop with a contact-shadow receiver.
The photograph and board use the same fixed projection and resize together;
drag, wheel, color changes and resume cannot rotate or zoom the viewpoint.
There are no camera controls or external runtime texture/model downloads.

The built-in image generation tool created the photograph with this prompt:
"Photorealistic dark warm music room, authentic upright piano on the right,
warm wall lamp on the left; generously wide but shallow tall matte dark walnut
writing table in the foreground, empty central tabletop; a real curved walnut
chair with charcoal leather upholstery opposite the seated viewer; centered
elevated perspective, subtle grain, believable lighting, no chessboard,
pieces, people, text, plastic or toy geometry." The original source is
`/Users/jasonpark/.codex/generated_images/019ef57c-0909-7363-88f8-5f655993f3ac/exec-ad1a2100-234b-4743-81e6-526bc7dcc7cf.png`.
Earlier `chess-room.webp` / `chess-walnut.webp` assets remain preserved but are
no longer loaded by this renderer.

## Collaborator Design Integration

The collaborator's `main` at `23778ed` was merged into `frontend` without
discarding the existing chat/DAW functionality. The integration merge is
`a880236`. The studio, panel, arcade and web app primary stylesheets match
that collaborator revision exactly. The global game-style override import
was removed; new room chrome is scoped to `.chess3d-shell`. The collaborator's
upright side-panel lobby and Ear Training solo screen are retained.

The following verification/deployment entries describe the earlier reference
build; the integrated release is verified separately below after rebuilding.

Existing chess room rows keep `game_type: chess` and store the variant in
`captured.presentation: 3d`. Creation, moves, rematches and resume preserve it;
invites identify `chess_3d`. Existing multiplayer, AI and promotion flows are
reused. Legal 3D targets and check highlighting use chess.js. WebGL loss or
absence falls back to the playable 2D board. Hidden panes pause rendering;
unmount disposes geometry, textures, shadows and the GPU renderer.
